# Báo Cáo Fix Bug: Sự cố `max_tokens` với `langchain-ollama`

**Ngày thực hiện:** 15/06/2026
**Thành phần:** `src/agent_graph.py` (Luồng Inference Core)

## 🎯 BỐI CẢNH SỰ CỐ
Trong quá trình chuyển đổi kiến trúc sang sử dụng `langchain-ollama` kết hợp với tính năng `with_structured_output` của Pydantic, hệ thống đã gặp lỗi sập luồng (crash) liên tục.

- **Log lỗi:** `Router error: AsyncClient.chat() got an unexpected keyword argument 'max_tokens'`
- **Nguyên nhân (Root Cause):** Lớp `ChatOllama` trong thư viện `langchain-ollama` hiện không hỗ trợ hoặc không xử lý được tham số `max_tokens` tự động sinh ra khi gọi hàm ép khuôn JSON (`with_structured_output`) của LangChain.

## 🛠️ PHƯƠNG ÁN XỬ LÝ (RESOLUTION)
Thay vì chờ đợi bản vá (patch) từ thư viện, đội ngũ đã thực hiện kỹ thuật **Bypass** bằng cách đổi sang sử dụng `ChatOpenAI` (vốn hỗ trợ đầy đủ các tham số chuẩn) và trỏ thẳng về cổng API OpenAI-compatible của Ollama.

### 1. Thay đổi thư viện Import:
- **Đã xóa:** `from langchain_ollama import ChatOllama`
- **Sử dụng:** `from langchain_openai import ChatOpenAI`

### 2. Cập nhật cấu hình khởi tạo LLM:
Cấu hình mới sử dụng `ChatOpenAI` nhưng kết nối ngầm về tiến trình Ollama cục bộ.

```python
llm = ChatOpenAI(
    base_url="http://127.0.0.1:11434/v1",  # Trỏ về cổng OpenAI-compatible của Ollama
    api_key="ollama-local",                # Bypass xác thực
    model=os.getenv("MODEL_NAME", "qwen3.5:4b"),
    temperature=0.1,
    max_retries=5,
    timeout=120.0
)

# Khởi tạo structured output với Pydantic (Giữ nguyên)
structured_llm = llm.with_structured_output(ReasoningOutput)
```

## 🏁 KẾT QUẢ
- Sự cố `unexpected keyword argument 'max_tokens'` đã được khắc phục hoàn toàn.
- Hệ thống tiếp tục khai thác hiệu năng của Ollama thông qua chuẩn giao tiếp API đáng tin cậy hơn, bảo đảm luồng Structured Output luôn trả về JSON an toàn.
